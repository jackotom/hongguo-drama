# 红果短剧 5.7

状态：5.7（内部5.7.0）源码／发行目标，尚未正式发布。此前正式版为5.6；三端成品与对应源码齐备、Mac签名／Apple公证Accepted／装订核对通过后统一发布。

## 改动

- ByteVC2片源由独立Librempeg组件转换为兼容H.264；普通H.264／HEVC继续优先且不额外转换。在线准备、下载和NAS共用转换路径，支持进度、取消及半成品清理；保留分集身份、画质、加密信息与完整时长校验。
- 观看记录确认同剧后不再重复提示；独立显示不拆散余组，也不吸入原在组外的自动同族记录。保留恢复自动分组入口，标记手动状态，按钮分两行，完成标记移到最近观看行。
- 音量、静音与常用倍速跨视频／剧集／重启记忆；新资料默认音量50%，播放前即恢复。临时长按2倍及松手／失焦恢复不覆盖常用值。
- App明确拒绝注册／取源时，其他支路的超时不再触发单任务无效自动重试。10秒是本机注册冷却，不代表上游一定恢复。

## 已有开发验证

ByteVC2在本机arm64开发版真实完整转换、在线播放、直接下载和取消清理已有证据，见 `bytevc2-playback.md`。#96–#98的三项定向回归、前端构建、隔离资料中的分组流程和两集真实素材静音播放／重启偏好已检查，见 `local-issues-96-98.md`。这些不是本轮最终发行包或其他架构的验收回执。

本轮构建与成品验证证据保存在 `.planning/release-5.7/`，发布后补记实际结果。

## 边界
