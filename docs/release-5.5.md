# 红果短剧 5.5

状态：发行候选，尚未发布 5.5。当前正式下载为 5.4。

## 修复

- 针对连续切集和批量下载时的空响应，播放取源使用独立匿名设备身份，保留一次备用主机尝试；不再等待共享设备的一分钟恢复窗口。上游限流或网络失败仍可能出现。
- 内联片源缺少解密元数据时，有界尝试原模型提供的备用接口；核对视频身份、完整时长、实际画质及明确加密状态，继续拒绝预览、错集和非法地址。详见 [恢复范围](inline-playback-metadata-fallback.md)，备用解析沿用贡献者 roytjus 的 PR #92。
- 删除 NAS 文件前重新核对挂载设备、目录及任务保存位置；新普通下载任务同样记录落盘目录身份，下载和删除前校验。校验失败保留文件和记录。
- 先保存停止/暂停计划，再取消下载和自动重试；保存失败恢复原状态并提示。
- 合并空间预算覆盖最终复制所需额外输出，提前拒绝空间不足的任务。
- 代理密码通过系统安全存储加密，旧明文和地址内嵌密码迁移后从普通设置移除；安全存储不可用时仅本次运行保留并提示，解密失败不擦除旧密文。
- 电视搜索取消立即结束界面等待；打开文件夹及批量暂停/启动失败显示错误。
- NAS 迁移改变当前视频地址时保留暂停状态与正常续播位置，避免重新开始播放。

## 下载资料与 NAS

- 不再新建每集 NFO，只保存整剧封面、简介和 `tvshow.nfo`；资料以来源实际提供为准。
- 设置新增「普通下载保存整剧资料」。将普通下载目录设为已挂载的 NAS 后，可沿原下载流程自动保存资料和创建剧名目录，无需反复进入独立 NAS 按钮。
- NAS 按钮默认开启「自动创建剧名文件夹」；已选中现有剧目录时可取消，沿用直接写入所选目录的方式。
- 已有分集 NFO 保留并兼容读取。NAS 用目录级隐藏身份索引安全复用视频，错剧号、错分集、链接或损坏的资料不覆盖。
- 同一目标目录的资料准备串行执行，先确认整剧身份再写简介和封面，避免两部剧并发混写。
- 普通下载继续遵循看完自动删除偏好；直接 NAS 下载继续跳过自动删除。已存在的备份不会被本轮迁移或清理。

## 单集评论与本机互动

- 播放器直接提供「当前集评论」，展示当前来源实际公开的内容；可能仅有部分评论，来源缺失时明确提示。
- 整剧收藏继续保存在本机，新增按集切换的小红心并在界面明确标注「本机」；不改变来源公开点赞数，不暗示同步红果账号。
- 本机收藏、小红心在当前资料目录中保存，切集、刷新评论和再次打开仍保留。

## 待验与边界

2026-11-03 根据 GitHub 最新问题修订源码。此前 4f7d9c7 候选的 CI 和桌面回执只证明此前候选，不能用于本次新修复。按用户明确要求，不再运行功能、单元、集成、桌面或硬件测试，也不重新下载或播放测试视频；本轮仅进行必要源码静态审查、发行构建、签名/公证/装订及文件完整性核对。发行完成后另补新冻结提交和构建回执。

实体 NAS/电视、真实手机授权、实体 Intel/Windows/GPU、干净 Gatekeeper、长期弱网及完整应用内跨版本更新仍需对应环境验证。Windows EXE 尚未签名。安全存储密文可能绑定本机，换机需重新输入代理密码；历史旧备份可能仍含原明文。

旧普通任务没有历史设备信息，无法倒推升级前是否已换挂载；实际重试、重新提交或补登记时建立当前可用目录身份。索引补写失败但原任务/源文件仍在时，可重新点击 NAS 进行校验与补齐，无需先删除视频。
