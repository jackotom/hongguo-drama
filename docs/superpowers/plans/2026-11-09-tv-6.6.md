# 6.6 TV 开发实施方案（Issue #120）

> 2026-11-10 执行更新：用户明确改用 `gpt-6.1-sol` / `high` 子控开发，`gpt-6-astra` 继续逐阶段审核；替代下文旧 DeepSeek 实现与路由前置要求。另授权读取当前 GitHub 问题并进行优化修复，先核实根因，保留原测试、来源和发行边界。

> 执行方式：主控审核、DeepSeek 子控实现，逐任务交付和退回。采用 subagent-driven-development 的任务隔离与审核流程；用户指定模型和本项目验证预算优先。

**目标：** 以 6.5 冻结源码为基线，交付可由遥控器完整使用的 6.6 TV 本地候选，支持红果观看流程与官方弹幕聚合，并形成逐设备兼容回执。

**架构：** 保留 Android WebView 原生壳和轻量 TV 页面；复用项目取源、签名、解密与 Android 媒体准备逻辑。TV 独立界面和包身份；不复制手机底栏，不重写取源协议。

**技术：** Java / Android SDK、WebView、JavaScript、现有 esbuild、Node 内置测试；不预设新增依赖。

**阶段状态：** 已读取 Issue 正文及全部四条评论、核对代码和发行规则；已取得 gpt-6-astra 只读方案审查。本文件为方案交付，不代表实现、构建、安装或发布完成。

## 3. 功能和平台差异

| 维度 | TV 6.6 方案 | 与现有版本的处理 |
| --- | --- | --- |
| 主要流程 | 遥控发现、搜索、详情、选集、观看、本机收藏与记录 | 复用业务，优先完成看剧闭环；不承诺桌面所有设置和工具 |
| 界面 | 横屏、大字、清晰焦点、安全边距，按可用宽度确定列数 | 不直接放大桌面，也不沿用手机四底栏；竖屏视频等比显示，默认不裁字幕 |
| 操作 | 方向键、确认、返回、媒体键；无需鼠标或触摸 | 输入框保留编辑和输入法行为；关闭弹层后返回原控件，列表返回保留位置 |
| 全屏 | 网页播放层保留弹幕、控制和焦点 | 避免系统视频全屏吞掉网页弹幕；关闭控制层、退出全屏、返回详情分层处理 |
| 播放准备 | 复用 Android 有界恢复，完整单集准备后播放 | 保留 64MB 限制；不把手机或桌面实测当作 TV 解码能力 |
| 编码 | 按既有候选顺序尝试 H.264／HEVC，解码依赖实际设备 | 不新增 H.264 排序承诺，不降低固定画质约束；无普通编码候选时 ByteVC2 明确提示不支持，不伪装加载成功、不悄悄无限重试；本轮不移植桌面转换器 |
| 官方弹幕 | 读取真实弹幕，沿用 6.5 的 5 秒分组窗口，显示“内容 × N” | 同内容按组首时间窗口聚合，非无限滚动合并；暂停／跳转／切集同步；无弹幕或接口失败不阻断视频 |
| 语言 | TV 使用明确中文界面，正文、剧名保持原文 | 本轮不新增完整 TV 英文翻译需求；桌面中英文能力保持现状 |
| 数据 | `io.github.hongguo.tv` 独立包，本机收藏／历史 | 不读写手机包资料，不承诺云同步或桌面记录迁移 |
| 服务端 | TV 本机独立取源 | Docker 继续用于搜索、下载、合并；不要求 Docker 常驻、不增加远程转码服务 |
| 来源与其他能力 | 红果；播放临时缓存 | 不接色情源、不扩海外源、不增加 NAS、离线库、账号云收藏、发送弹幕 |

稳定性应拆分：注册／网络、媒体候选、实际解码和播放器状态。注册仅对现有可重试类型在 10 秒冷却后再试一次；候选最多四个，取消后不得发起新请求；明确业务拒绝立即结束。网络备用成功不等于解码成功：只有出现有效帧才进入播放状态；解码失败应呈现可遥控操作的重试／换集，并保留观看进度。不得宣称已具备桌面完整自动降档。

兼容门先保留 `minSdkVersion=29` 和已知打包目标，探测实际 WebView 必要能力。`chrome100` 是编译目标，并非已证明的最低 WebView 支持版本。荣耀若不满足要求，先列出现有 Java API、JS API 和媒体差距，再由 Astra 判断最小兼容补丁；只改 minSdk 数字不能通过验收，也不能将荣耀悄悄移出目标。若需要原生播放器重写或大范围低版本支持，单列范围与成本后再决定。

## 4. 主控、子控和审核制度

- **gpt-6-astra：** 需求／方案审核负责人；批准每个任务边界，审代码、核验子控证据，负责最终通过或退回。根会话负责工具编排和汇报，不冒称已切换运行中的主模型。本轮已真实调用 gpt-6-astra 完成只读审查。
- **DeepSeek：** 具体代码实现、定向回归、修复审核意见和提交交付说明。必须使用当前网关实际支持的完整供应商限定模型 ID，并用真实路由回执核验供应商；不接受模型自报身份作为证据。
- **当前阻碍：** 本轮读取 `/Users/buzhi/.codex/config.toml` 未见 `agents.default_subagent_model`，当前可用子控模型列表未提供 DeepSeek。因此未派发 DeepSeek、未改实现代码，也不默换其他模型。配置中的主模型名称不能证明某个已运行会话的实际身份。
- **单任务门：** 子控提交文件列表、行为变化、测试命令与真实结果、遗留风险；Astra 先核对需求再审实现。取消失效、越界写入、身份校验放宽、无限重试、假成功、丢失记录或焦点陷阱任一存在即退回。
- **并行方式：** T2 媒体共享和 T3 焦点纯函数／样式可并行，禁止同时编辑 `app.js`、构建入口或 MainActivity。共享接线由一个子控串行完成。T4 弹幕等待 T2/T3 的播放器生命周期稳定后接入。不为凑人数重复审查。
