## #101：批量失败

只读调查已确认：App拒绝只停止当前任务的自动重试，队列收尾仍立即派发后续任务；匿名注册冷却期间，后续任务可继续被标记失败。这是本地队列保护缺口，不能据此确认113集阈值或上游恢复时长。

现遇结构化匿名设备注册失败或 App 取源 HTTP 403/429，暂停尚未开始的数字红果任务和已有延迟重试任务。保存暂停状态成功后，再取消对应重试定时器；下载管理显示原因，可手动重试、选中重试或全部开始。已在传输的文件和其他来源继续原流程。普通单集业务错误、缺模型、画质不可用及 CDN 权限错误不会触发这项全来源保护，不新增猜测的解封倒计时。明确拒绝也不再通过同任务画质回退继续重复取源。

验证：

- `node scripts/check-download-source-rejection.cjs`：9/9通过。新增断言先复现暂停持久化/资源取消顺序的2项失败，修正后通过；覆盖拒绝后停止派发、重启保留、正在传输、其他来源、迟到回调、手动恢复、画质回退与保存失败。
- `node scripts/check-source-retry.cjs`：原有15/15通过。

保存失败时，只能保持当前进程内的暂停保护，不能保证重启后仍暂停。测试使用隔离资料和模拟网络，不是百集实网压力测试；113集阈值、上游拒绝根因及恢复时间仍未证实。

## 横屏双击播放区域全屏

双击处理原来只绑定视频元素；“保持宽度”等情况下，视频元素外的播放区留黑位置没有响应。现统一绑定播放舞台：双击视频或播放区留黑位置进入全屏，再双击退出；沿用现有全屏动作，保持播放/暂停状态。按钮、进度条、菜单和对话框不触发这项动作，视频自身不再重复绑定，避免冒泡时切换两次。

`node scripts/check-player-gestures.cjs` 新增舞台范围断言先失败，修复后通过；覆盖适应窗口/保持宽度、播放/暂停状态、全屏进入/退出及控件边界。`npm run build:react` 通过（680ms），既有 Vite 提示不变。本次两项必要检查完成，未运行额外全量回归或实机点击验收。

## 可配置的短按／长按快捷键

设置 → 播放快捷键新增独立的“长按临时 2 倍速”，与原有播放／暂停、切换全屏一样可自行改键并即时保存。播放／暂停与长按倍速允许共用同一键，其他动作仍禁止冲突；新资料默认两者均为空格。

共用键短按在松开时播放／暂停，按住300毫秒临时2倍速，松开或窗口失焦恢复原有倍速，长按结束不额外暂停或快进。暂停时长按倍速键会开始播放；恢复的是原倍速，不会将临时倍速写入偏好。单独设置倍速键后，该键短按不触发播放／暂停。原快进键的短按5秒、长按2倍速行为保留。

已有有效自定义设置保留，缺少新项时将长按倍速键补为原播放键，避免空格已被另一个动作使用时覆盖用户设置。输入框、菜单、弹窗和系统组合键沿用原边界。
