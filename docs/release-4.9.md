# 红果短剧 4.9

状态：发行候选，内部 `4.9.0`，标签目标 `v4.9`。用户已授权完成验证后发布GitHub；当前下载仍保留4.8，最终构建、签名公证和远端核验完成后补记。

## 老电脑兼容播放

在线播放清晰度新增“老电脑（H.264优先）”，选择会保存。红果优先取兼容片源；开启兼容模式时，已知H.265片源先转H.264，再送入播放器。复用既有取消、预取、失败重试、暂停与进度恢复。默认自动1080P优先及手动固定画质行为保留，不修改已有下载原件。较慢CPU仍需等待转码。详见 [兼容播放](legacy-playback.md)。

## 普通小窗与Dock图标

4.8已复现：自带画中画、隐身小窗触发Electron跨全屏处理后，整个应用的Dock图标消失。4.9改用macOS原生面板承载同一个实时播放器，跳过全应用进程类型转换，保留普通小窗的Dock图标与跨其他应用全屏能力。隐身小窗退出、关闭或Esc后归还原视图，不重开播放器；修复隐身样式误隐藏外层容器的空白画面。

## 老板键

设置中位于“切换全屏”右侧，单独启用。点击录入按钮，按Ctrl、Cmd、Alt组合或F1–F12，再点保存；Esc、Tab或失焦结束录入，不能直接删改键名。使用物理字母键兼容macOS Option输入；占用或保存失败保留旧绑定。

按一下立即静音、暂停并隐藏主窗口、自带画中画与隐身小窗；Mac同时隐藏Dock图标。再按恢复原来可见的窗口与Dock，保留进度和暂停状态；原来就隐藏的窗口不额外显示。快速连按时，旧的异步Dock恢复和音频恢复不能重新暴露已隐藏的应用。

老板键隐藏期间仍可用同一个全局组合键恢复。普通画中画、隐身小窗的Dock行为保持正常，不通过恢复4.8的进程类型转换实现。

## 本地验证

本机Apple Silicon / macOS，独立验收应用、资料与下载目录；标准main.js，无快捷键回调替换。使用此前从红果实时目录随机选择并真实下载的《认下混混老爹，我一路青云》第1集副本，9,570,005字节、1080×1920，未使用彩条或生成视频。

用户明确授权macOS原生键盘、鼠标事件后，以CGEvent发送真实全局按键：

- 主窗口、自带画中画、隐身小窗三种播放场景均确认窗口和Dock一起隐藏，第二次按键恢复原可见窗口；视频保持暂停，进度至少5秒不变化。
- 隐身小窗恢复后鼠标移出、移回，仍不自动播放。自带画中画退出后可直接手动继续播放，不需要重新选集。
- 此前疑似“画中画退出后不能手动播放”来自验收鼠标事件缺少点击计数；修正验收工具后，正常播放器通过实测，本项未修改播放器代码。
- 播放器自身未静音、音量100%，启动--mute-audio兜底保证扬声器全程静音。隐藏时相关webContents立即静音，恢复原静音偏好后仍保持暂停，无可听内容；没有关闭测试静音进行人工听音。
- 老电脑模式保留原31项定向回归和真实H.265转H.264验收；两个普通小窗的Dock常驻、跨全屏及退出恢复已有本地4.9包证据。老板键录入与原生控制回归覆盖取消、删除键、保存、占用、磁盘失败和快速连按。

本地证据：`.planning/release-4.9/` 与 `.planning/boss-key-acceptance-20261030/`。最终签名包的三端发行验收尚未完成，不以试用包结果代替。
