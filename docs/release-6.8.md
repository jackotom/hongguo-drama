## 画中画改动与验证

- 子控使用用户指定的 `gpt-6.1-sol`、`high`；主控复核最终改动及检查证据。
- `useFloatingPlayer.js` 在打开小窗、视频元数据与实际尺寸变化时发送宽高；不重新挂载或替换播放器，横竖切集保持原播放状态。清除浮窗内继承的窗口填充定位，允许内容缩小。
- `preload.js` 仅暴露传递宽高的窄桥；`floating-player-window.js` 只接受可信主窗口的主frame消息，拒绝非数值、越界和异常比例，浮窗仍无preload、无Node权限且不能导航或再开窗。
- 内容比例补偿原生边框；最小内容尺寸以160×90约束并按视频比例调整，最大尺寸以所在显示器工作区为界；移屏、屏幕移除、横竖切换均约束至屏幕内。保留防抖尺寸记忆与Mac Dock身份。
- 唯一画中画检查命令：`rtk proxy node scripts/check-floating-player-window.cjs`，退出码0。通过窗口回归及内含的host回归，覆盖实际preload桥链路、横竖切换、边框补偿、缩小与放大、屏幕范围、消息来源校验、记忆和关闭恢复。
- 检查使用离线窗口／媒体节点夹具，没有实际播放视频。软件解码若始终不给出视频宽高，保留原窗口比例；真实视频GUI及各平台原生拖动体验待验。
