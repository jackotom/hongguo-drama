## 本轮修复

- 对应 GitHub Issue #177：发现页不再为每部档案串行调用 `get-series-episodes`，改为轻量内存进度快照加当前页逐部异步预热。
- 播放页剧集面板先显示缓存进度，再逐部异步补齐；分集扫描改为异步文件操作，并在扫描与本地播放地址签发之间分批让出事件循环。
- SMB／NAS 目录可达性探测最多等待 4 秒；掉线或超时只延迟角标，不阻塞窗口、菜单和 IPC。
- 单部剧扫描不重叠；下载任务变化会清空进度缓存。文件身份、目录身份、路径冲突、同尺寸内容变化、本地播放授权与删除前复查仍保留。
