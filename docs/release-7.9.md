# 7.9 四平台发行目标

状态：源码／发行目标。公开版本 `7.9`，内部版本 `7.9.0`，桌面构建 `7.9.1`。尚未公开，Latest 仍为 `v7.8`。

发行范围：macOS Apple Silicon arm64、macOS Intel x64、Windows x64、Linux x64 AppImage。Docker、TV APK与手机APK不在本轮附件或验收范围。

> **Android手机APK／Android TV版：** 请前往 [N3urda/hongguoTV](https://github.com/N3urda/hongguoTV) 下载。该项目独立维护；版本、兼容性与测试状态以该项目发布页为准，不计入本项目的四平台附件或验收。

## 本轮修复

- 对应 GitHub Issue #177：发现页不再为每部档案串行调用 `get-series-episodes`，改为轻量内存进度快照加当前页逐部异步预热。
- 播放页剧集面板先显示缓存进度，再逐部异步补齐；分集扫描改为异步文件操作，并在扫描与本地播放地址签发之间分批让出事件循环。
- SMB／NAS 目录可达性探测最多等待 4 秒；掉线或超时只延迟角标，不阻塞窗口、菜单和 IPC。
- 单部剧扫描不重叠；下载任务变化会清空进度缓存。文件身份、目录身份、路径冲突、同尺寸内容变化、本地播放授权与删除前复查仍保留。

## 验证门槛

- 定向回归覆盖：首屏零触盘、当前页预热、扫描不重叠、网络目录等待期间主进程继续响应、详情页重新校验替换目录与同尺寸篡改。
- 冻结源码全量 `npm test`、生产前端构建、源码 CI。
- 双 Mac 本轮重新 Developer ID 签名、Apple 公证接受并装订；最终 arm64 包使用真实红果素材静音播放，x64 至少完成 Rosetta 启动。
- Windows x64 在 GitHub Windows 虚拟机完成真实 App 下载队列、静音播放、新装、同版重装和真实 1.80 升级资料保留；EXE 未签名。
- Linux x64 AppImage 在原生 Ubuntu runner 启动并完成真实两集静音播放。
- 四平台新包、更新清单、精确源码、对应媒体源码及 `SHA256SUMS.txt` 同源汇总，远端大小与摘要及匿名入口核对后一次公开并设 Latest。

## 已知边界

- 进度角标允许延迟；缓存过期后先显示旧值并在后台刷新。外部直接增删文件时，角标可能短暂滞后，详情页仍会重新校验实际文件。
- 未复建用户同一 SMB 挂载、22 部／2380 集生产档案；自动化覆盖使用隔离夹具和临时目录。
- Intel Mac 通过 Rosetta 启动不等于实体 Intel 设备验收；Windows EXE 未签名，虚拟机结果不代表实体 Windows、独显或长期稳定性。
