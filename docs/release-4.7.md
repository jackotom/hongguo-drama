# 红果短剧 4.7

**状态：发行候选，尚未正式发布。** 内部版本 `4.7.0`，计划标签 `v4.7`。用户已确认本轮正常测试版可用，并授权正式上传发布。

## 修复

- 下载任务提交失败后，手动“重试本集”可再次提交；提示依据真实任务状态，不再把失败尝试描述成已有下载任务。
- App 取源区分缺少兼容编码与指定在线播放清晰度不可用，提供具体安全文案。显式选择 1080p 时仍不静默降级。
- 首次匿名设备注册失败改为短暂冷却，后续请求可在同一进程中重新尝试；不必长期保留失败状态。
- 自带画中画定位到主窗口所在屏幕右下角，明确显示、聚焦并保持置顶；保留尺寸记忆与小屏适配。
- 修复拖动本地视频进度时取消旧读取可能触发 `ReadableStream is already closed` 的主进程异常。

## 已有验证

- 用户已完成正常测试版试用。215 项单元测试、96 项平台检查及后续受影响补测通过；新增流取消回归先复现错误，修复后通过。
- 随机选择真实红果短剧，实际下载并静音播放；手动重试后真实提交、两种画中画、关闭返回、尺寸保存、片尾连播及测试副本自动删除通过。自动删除验收后已关闭，正式资料未受影响。
- 此处是本地测试证据；最终 4.7 的三端构建、Mac 签名公证、Windows CI 与远端附件核验待本轮完成后补记。

说明见 [下载与重试验收](issue-71-download-retry.md)、[画中画验收](issue-72-picture-in-picture.md)、[注册恢复](issue-70-device-registration.md)。Issue 70 作者通过恢复自动 DNS 解决其环境问题，不将作者恢复归因于本地修改。

## 验证边界

Mac 最终发行需 Developer ID 签名、Apple 公证 Accepted 和装订；Windows EXE 未配置代码签名。未覆盖实体 Windows/Intel、干净 Gatekeeper、长期播放与完整跨版本应用内更新。用户报告未提供相同片源与运行环境，不能声称覆盖全部个案环境。发行不替换本机正式安装。
