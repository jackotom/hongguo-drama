# 本机播放模型提供方与 v5 研究记录

## 改动与适用范围

正式 v7.4 的匿名注册可以成功，但播放模型接口仍可能 HTTP 200、正文0字节。旧单集 Gorgon／Argus／Ladon 兼容请求也在本轮真实样本上失败。重试次数与注册成功均不能作为正片已恢复的证据。

`metasec-bridge.js` 为单独运行的本机模型提供方增加受限 stdio 协议。桌面在以下位置找到 `hongguo-metasec`（Windows 为 `.exe`）时启用：

- 打包资源的 `metasec/`。
- 开发目录的 `build/local-metasec/`，已加入 Git 忽略。

没有提供方时保留原取源逻辑。该提交不包含 v5 签名器、SDI 实现、官方 SDK 片段、提供方二进制或它们的自动下载／构建脚本；标准桌面与 Docker 构建不会因此自动获得 v5 取源。本项集成仍处于草稿阶段。

## 协议与保护

父进程启动固定本地路径的程序，参数为 `--serve <应用私有缓存目录>`。每行请求只有本次请求号和数字分集编号：

```json
{"id":1,"vid":"7703906910138813464"}
```

成功响应为同一 `id`／`vid`、`success: true` 和 `response` 播放模型对象；失败响应为同一 `id`／`vid`、`success: false`、白名单错误 `code` 与可选 HTTP `status`。桥接不接受请求方传入 URL、账号 Cookie、命令或任意路径，也不把提供方原始错误交给界面。

- 单个在途请求，30秒上限，响应缓冲不超过2 MiB；取消／超时终止进程并拒绝迟到结果。
- 请求号和分集号必须匹配；模型继续经过既有完整时长、尺寸、清晰度、编码、地址与加密信息校验。固定1080P不静默降级。
- 清除继承的调试与只复用实验环境变量；不保存提供方 stderr、签名、会话或媒体地址。退出应用时关闭提供方。
- 本机实验提供方仅在自己的进程中保留新注册匿名身份与 SDI 会话；没有使用用户登录账号、其他项目附带的设备身份或共享会话。

## 已完成的独立研究

参考 [it00021hot/hongguo-desktop 固定提交](https://github.com/it00021hot/hongguo-desktop/tree/374b1819b0c4ae2f77cf6008e1c138f92f1f16bd) 的 MetaSec v5／SDI 实现，在项目外建立隔离 Rust 研究程序；使用自行注册的匿名身份和经区间、摘要、解压长度校验的官方 SDK 片段。

随机目录选中的《流水线逆袭，段总一眼动心》（seriesId `7703905003462724633`）结果如下，原始脱敏回执见 [JSON](source-v5-research-2026-11-16.json)：

| 分集 | VID | 实际尺寸 | 实际时长 | 完整下载后大小 |
| --- | --- | --- | --- | --- |
| 第2集 | 7703906910138813464 | 1080×1920 | 159.133333秒 | 12,140,956字节 |
| 第13集 | 7703907064573070360 | 1080×1920 | 176.680975秒 | 17,048,278字节 |

同一进程仅注册一次，先取第2集再跳至第13集，两次模型均 HTTP 200、业务码0，分别23233／23117字节。已有媒体解析和服务端下载代码完成官方 CDN 校验、实际下载、解密、尺寸与完整时长核对、前3秒解码。没有打开音频输出设备，也没有用预览或旧视频代替完整素材。

这些结果证明“新注册身份＋SDI会话＋v5签名＋对应接口”这一组合在两个样本上有效。未做逐项单变量对照，不能归因为唯一请求头，也没有证实上游切换时间、永久恢复、所有剧集或长期连播。
