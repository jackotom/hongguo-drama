# Issue 74：4.8 正式版 Dock 图标实测

日期：2026-10-30，Asia/Shanghai。

结论：本机复现。正常启动有 Dock 图标；应用自带画中画和隐身小窗都能使图标消失，退出小窗后仍不恢复。完整退出应用再启动可恢复。

## 环境与边界

- Apple M5 / arm64，macOS 27.2。
- 使用本机安装的正式版 4.8.0，代码签名严格验证通过；未重构建、未修改正式包。
- `app.asar` SHA256：`e0d997368c6a76a81252b46d3fbd9f7cfc5cd37dc53c79b7eb0be253e8c0432d`，与 4.8 发行留档一致。
- 使用独立 profile 和下载目录；启动带 `--mute-audio`，界面播放前另行静音，播放中确认 `video.muted === true`。
- 通过原生应用界面点击开关；只读主进程诊断记录 `app.dock.isVisible()` 和窗口状态。macOS `NSRunningApplication` 独立确认触发后 activationPolicy 为 accessory（1）。
- 初次选择应用时工具短暂启动了默认资料实例，随即退出，未播放或切换小窗。以下全部验收均在已验证路径的独立资料实例完成。

## 真实素材

本轮从红果实时目录随机选择《认下混混老爹，我一路青云》，series_id `7696744349203188760`，实际下载第 1 集，9,570,005 字节。播放解码尺寸为 1080×1920。未用彩条或测试图；自动删除关闭。

## 过程与结果

| 操作 | Dock 图标 | 窗口结果 |
| --- | --- | --- |
| 正常启动 | 存在 | 主窗口可见 |
| 静音播放真实下载视频 | 存在 | 画面和时间正常推进 |
| 打开应用自带画中画 | 消失 | 主窗口与画中画均可见，小窗跨桌面可见 |
| 退出画中画 | 仍消失 | 画中画关闭，主窗口可见 |
| 完整退出再启动 | 恢复 | 主窗口可见 |
| 打开隐身小窗 | 消失 | 主窗口变为跨桌面小窗 |
| Esc 退出隐身小窗 | 仍消失 | 主窗口恢复，跨桌面状态关闭 |

第一次在播放按钮自动隐藏时点击画中画没有打开小窗，诊断仍为 Dock 可见；暂停显示按钮后重新点击，确认第二个窗口实际创建才记录有效画中画结果。

两条触发路径共同涉及 `setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true })`：`src/native/floating-player-window.js:164` 和 `src/native/stealth-window.js:35`。隐身退出调用位于 `src/native/stealth-window.js:20`。现有证据把问题定位到跨桌面窗口切换后的应用显示状态；本轮未修改或验证修复。
