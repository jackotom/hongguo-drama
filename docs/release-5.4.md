# 红果短剧 5.4

**状态：已正式发布。** 5.4（内部 `5.4.0`）已于 2026-11-02 18:25（Asia/Shanghai）正式发布，标签 `v5.4`，冻结源码 `e7595c040d328655212a2fb0b315286a6ee914b2`。恢复播放请求签名，增加官网登录、按剧清缓存、观看记录分组与 DLNA 单集投屏。三端16附件远端大小及SHA256匹配；双Mac App与DMG四份Apple公证Accepted、签名/装订、只读挂载与更新ZIP恢复通过。源码CI41425248571、Windows CI41425313110通过232单元及102平台检查；Windows便携11项、安装/重装/真实1.80升级资料保留9项通过，EXE未签名。最终arm64包随机真实两集1080P HEVC/AAC下载和静音约10秒播放通过；x64 Rosetta启动退出通过。

## 变化

- 恢复播放请求签名，按最终 query、POST 正文和时间戳计算；备用主机或更新设备后重新签名。注册初始化不再消耗播放请求预算，空响应时有界重试，不承诺消除全部上游错误。
- 「红果账号」新增「使用官网登录」备用入口。官网窗口已验证提供手机号验证码和扫码方式；凭据验证后由系统安全存储加密，取消、退出、窗口关闭后不能被迟到请求重新登录。真实手机授权未由本轮代办。
- 从剧库永久移除时清理本剧未占用的在线及兼容播放缓存，补清旧分集与中断残留；保留下载视频、其他剧和正在读取或投屏的文件。命名歧义拒绝清理，清理失败保留剧库记录供重试。
- 观看记录按明确季号分组，高季在前；支持展开/折叠、人工确认同剧、移出分组、恢复自动分组和已看完标记。疑似关系先提示，展示分组不改变更新检测、红点或系统通知，分组保持子来源隔离。
- 播放器底部新增同局域网 DLNA 单集投屏。电视需启用 DLNA；在线投屏先完整缓存本集，提供播放、暂停、停止和取消。仅向选中的电视提供随机媒体能力地址，不传递平台凭据或原始媒体链接；格式支持以电视为准，实体电视尚未验收。

## 本机复审修复

- 清缓存等待期间不再使用旧剧库快照覆盖其他剧的修改；只扫描兼容缓存目录第一层普通文件，避免触及其他目录、符号链接及冲突文件。
- 本地媒体读取登记引用，结束或取消后释放；读取和投屏占用的文件不进入删除。
- 投屏 Stop 可中断尚未完成的控制请求；旧电视 Stop 失败时保留旧会话。连接和停止失败后，界面按主进程实际状态更新。
- 两处旧测试夹具补入新分组模块，并修正取源失败时不显示解码修复按钮的旧断言。真实解码失败仍保留兼容转码。
