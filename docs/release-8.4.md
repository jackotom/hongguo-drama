# 8.4 四平台发行候选

状态：发行候选（Draft），四平台构建、签名公证与实测验收完成后统一公开并设 Latest。公开版本 `8.4`，内部版本 `8.4.0`，桌面构建 `8.4.1`。

发行范围：macOS Apple Silicon arm64、macOS Intel x64、Windows x64、Linux x64 AppImage。Docker、TV APK 与手机 APK 不在本轮附件或验收范围。

> **Android手机APK／Android TV版：** 请前往 [N3urda/hongguoTV](https://github.com/N3urda/hongguoTV) 下载。该项目独立维护；版本、兼容性与测试状态以该项目发布页为准，不计入本项目的四平台附件或验收。

## 本轮变化（8.3 → 8.4）

- **取源与网络加固**：修复本地代理环境下的重定向误判（校验目标 `Location` 而非代理地址），收紧四通道单源超时预算（9s/12s/12s/8s），DLNA 投屏支持多网卡逐一容错发送，为代理连通性测试与官网搜索补充响应体上限及并发去重。
- **主进程性能与 I/O 优化**：解密 Worker 改为零拷贝传输，本地媒体发布改为异步 I/O，HLS 磁盘容量检测增加节流并保留每块内存配额硬校验，历史记录查询消除循环内重复深拷贝。
- **播放器与前端优化**：节流播放进度/弹幕/合并进度更新，修复 React 生命周期竞态与离开搜索页时的全局滚动监听泄漏，拆分代理/更新 IPC 与播放器弹窗/选集器，补齐打包瘦身与前端分包。
- **工程与质量保障**：新增零依赖静态代码检查（`npm run lint`），覆盖语法、重复 JSON 键与残留 `debugger` 检查。
