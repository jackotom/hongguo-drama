# 7.8 四平台发行目标

状态：源码修复完成，四平台构建与验收尚未完成。公开版本 `7.8`，内部版本 `7.8.0`，桌面构建 `7.8.1`。

发行范围：macOS Apple Silicon arm64、macOS Intel x64、Windows x64、Linux x64 AppImage。Docker、TV APK与手机APK不在本轮附件或验收范围。

> **Android手机APK／Android TV版：** 请前往 [N3urda/hongguoTV](https://github.com/N3urda/hongguoTV) 下载。该项目独立维护；版本、兼容性与测试状态以该项目发布页为准，不计入本项目的四平台附件或验收。

## 本轮修复

- 下载管理定时刷新改为轻量任务快照，不再每 15 秒同步核验全部已完成文件。
- 打开下载管理后，延后一次串行文件核验；核验期间不启动重叠轮询，快速刷新也不能覆盖未完成的核验结果。
- 启动时已有完整文件身份的任务不再逐个重新读取；仅旧记录缺少身份或内容摘要时执行迁移读取。
- `hasCompleteTaskFile` 的目录身份、文件身份、路径冲突、媒体播放和删除前安全校验保留；显式核验仍会把丢失文件标为失败。
- 对应 GitHub Issue #176：近千条任务位于 SMB 网络盘，单轮同步文件检查约 25–40 秒，15 秒定时器持续叠加，导致主进程无法处理界面操作。
