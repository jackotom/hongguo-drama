# 下载临时目录与本地读取边界加固（2026-11-14）

本轮基于 7.2 后源码，未升版、未打包发行、未替换正式安装。

## 临时目录

- 临时目录新增绑定任务回执的随机 `.hongguo-owner` 标记。v2 正常目录继续严格核对设备号、inode 和创建时间；记录中为负的目录 ID 才使用设备号和随机标记兜底，不再要求不稳定的目录 ID 与创建时间匹配。负 ID 本身不证明文件系统类型。
- 无登记任务回执的旧目录、带未知文件或未知身份的目录继续原样保留，不按名称或固定标记内容猜测归属。
- 正常目录被替换后，即使复制标记也拒绝认领；负 ID 兜底不能辨别复制的有效标记，文件删除仍须逐个通过精确回执。路径操作后的最后竞争窗口不能由本方案完全消除。
- 仅剩有效标记时才移除标记并尝试删除空目录。未知文件、文件删除失败时保留标记；删除空目录失败或中途取消后，仅在目录身份未变化时排他恢复标记，供后续重试。不再要求打开目录句柄，避免不支持此操作的平台使所有 v2 目录无法清理。

## 本地读取

- 已登记任务在判完整、发播放令牌、投屏和打开目录前复查普通下载目录身份。
- 播放令牌携带实时校验，文件或目录被替换后旧令牌失效。
- 目录扫描只接受普通文件，拒绝目录和最终文件符号链接。

设备拒绝后的未接入自动续期分支已删除；生产播放继续使用每次重新申请的匿名播放身份。
