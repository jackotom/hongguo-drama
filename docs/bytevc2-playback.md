# ByteVC2 无法播放修复

本地开发分支 `fix/bytevc2-playback`，基于已发布5.6。未改变5.6标签、公开安装包或本机正式安装。

## 问题与来源

GitHub #95 的《我都元婴期了，你跟我说开学第四季》首集只返回ByteVC2，原播放器不支持。贡献者提供了使用Librempeg解码的线索。官方 `librempeg/librempeg` 固定提交 `cb1f8f3eef84999e61b27e2d44664858179bc240` 确有 `ff_bvc2_decoder`，其ARM优化代码还要求同时启用VVC解码器。

## 处理方式

- 优先使用原H.264／HEVC。只有选中ByteVC2片源时，才用独立组件转换为H.264，音频直接保留。
- 取源继续校验所选分集、真实尺寸、时长、加密元数据和媒体地址。ByteVC2没有可确认的身份、时长或尺寸时拒绝转换；固定画质不会借转换绕过尺寸要求。
- 在线播放及后续缓存会先转换；下载和NAS沿同一下载路径保存兼容视频。界面显示转换进度，可取消；未完整转换不发布为完成文件。
- 取消同时支持在线播放的AbortSignal及下载的CancelToken；原始解码诊断不写日志，避免泄露密钥或私有路径。
- Mac与Windows打包配置增加独立组件及许可证。固定源码构建脚本及对应源码归档见 `scripts/build-librempeg-source.sh`、`build/ffmpeg/LIBREMPEG-NOTICE.txt`。原FFmpeg二进制不替换。

## 验证记录

首集已从红果真实下载，1080P ByteVC2完整转换为1920×1080 H.264／AAC，时长136.997秒，转换约18.2秒。元数据接口一度DNS超时／上游空响应，之后恢复240集列表；最终随机选择第177集真实下载，其原始片源是正常HEVC，保留HEVC并沿用原FFmpeg路径，文件1920×1080、59.048秒，没有额外重编码。因此不可把整部剧一律当ByteVC2处理。

应用内验收使用独立资料、下载目录，以及已核实的真实首集编号，不使用测试图或彩条。关闭通用兼容模式后，首集在线播放成功，实际画面1080P、总时长2:16，全程静音；因原生界面工具往返，在42.8秒暂停，超过约10秒目标。随后退出应用清空内存缓存，重新直接下载首集，任务完成，实际文件为完整136.997秒H.264／AAC，本地播放成功并暂停。实际解码开始后取消转换也已验证：子进程退出、半成品移除、原下载输入保留。

定向回归：37项片源／备用校验、10项转换／取消／完整性检查、13项取源集成，以及原下载安全检查通过。前端构建、辅助构建脚本语法与双平台打包入口静态检查通过。没有运行全套回归、长批量下载或真实手机授权测试。

Mac arm64组件已构建并核对架构、系统动态库依赖和BVC2解码器。Mac x64、Windows组件尚未实际构建；此时不能宣称三端修复已交付。#96目前没有新的具体剧集或复现日志，百集后的匿名设备失败未被本次解码修复证明已解决。
