# 7.2 发行候选

内部版本 `7.2.0`，桌面构建 `7.2.1`。本文件为候选快照：尚未冻结、构建、签名、公证或公开，不作为新包验收回执。

用户于2026-11-13授权处理近期问题并统一发布7.2。#151官方中文字幕来源核实未取得可验证轨道后，用户对“继续提供样本，或先发已验证修复”的选择答复“你自己看着来”；本轮选择先发行#150与#153，#151保持未完成，不把空轨界面或另一中文剧集算作字幕支持。

## 本轮变化

- #153：外置exFAT空文件编号、截断后重新分配编号不再造成误报。使用原始独占句柄证明文件身份，仍要求有效正数编号、设备号、纳秒创建时间与路径一致；未知或被替换文件不认领、不覆盖、不删除。详见[外置盘修复](issue-153-external-disk-2026-11-13.md)。
- #150：用户选择仅移除记录时，不再因未知临时残留阻止移除；已完成视频和未知文件保留，不额外清理。活动任务仍先正常停止，其自身已验证临时产物按原取消流程清理。移除记录后旧临时回执也移除，遗留未知文件需用户自行处理，不能冒称已释放空间。
- #150：缺少ByteVC2组件在传输前停止；实际无法启动组件时作为本地故障返回，停止无效换源、降档和重复下载，手动重试重新检测。Windows原机为何偶发漏检组件仍未证实，不承诺根治所有系统环境问题。详见[下载与删除修复](issue-150-download-delete-2026-11-13.md)。
- #151：未接入中文字幕。DramaBox本轮返回403；已检查的ReelShort公开页面没有独立字幕轨道，中文版本使用不同剧集身份。详见[来源核实](issue-151-subtitles-2026-11-13.md)。
