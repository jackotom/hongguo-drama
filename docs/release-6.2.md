# 红果短剧 6.2

状态：本轮优化后的四平台发行候选，内部版本`6.2.0`，构建版本`6.2.1`；尚未公开本轮新包。不能沿用此前候选的构建、签名、公证、摘要或成品验收结果。未替换本机正式安装。

## 本轮修改

- 观看记录以同来源、同明确剧名的最高已看季为界，过滤缺失低季；有可见更新的组置顶。网络等待期间观看更高季时，迟到结果不再误报该季。
- 切集保帧增加新数据与定位完成的绘制兜底，覆盖帧回调缺失及新帧早于订阅；等待超过3秒提供重新加载或取消，暂停重载保持暂停。
- 抓帧按实际舞台像素分配，不超过原分辨率；软件解码暂停时明确提示，由用户点击继续启动。
- ByteVC2队列区分排队与转换，在线及下载均显示真实阶段；预缓存接管重放最后进度，不改变单进程、线程预算及取消清理。
- 前台取源异常保留终止码，停止无效清晰度降档及错误提示。

## 已有源码验证

- 本地完整源码回归及110项平台检查通过；前端构建通过。
- 帧交接回归、15项ByteVC2检查及20项预缓存检查通过；最高已看季并发回归9项通过。
- Ego独立渲染页使用本项目既有随机真实下载的两集1080×1920 HEVC/AAC，全程静音。5.7组件及修改版均可切集；缺失帧回调时暂停画面仍可撤罩，等待恢复入口与软解手动继续通过。这不是完整安装包或实体老电脑验收，#100原用户设备的持续卡顿尚未复现。
