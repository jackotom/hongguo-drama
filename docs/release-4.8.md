# 红果短剧 4.8

**状态：发行候选，尚未正式发布。** 内部版本 `4.8.0`，计划标签 `v4.8`。用户已确认自动清晰度测试版可用，并授权本次正式发行。

## 自动1080P优先

- 在线播放选择“自动（1080P优先）”，先尝试1080P；取源失败或播放中断后尝试720P，再尝试兼容片源。
- 解码不兼容时，优先保留当前画质的兼容转码与一次缓存重建，仍失败才换档；关闭兼容模式时直接换档。
- 换档保留播放进度与暂停/播放状态，不把临时低画质写成用户的固定选择；后续预取也从1080P开始。
- 一次播放有界尝试；手动重试、换集重新优先1080P，过期响应不能覆盖新选择。
- 手动指定720P/1080P仍不自动降级；已有本地文件不强制重下，其他来源沿用其支持的画质。
- 自动换档均失败后沿用本地文件/下载回退；下载默认“自动”时按1080P优先尝试，手动下载画质保留。

## 已有验证

用户已完成本地试用。19项清晰度、20项下载回退、22项续播/兼容回归，共61项通过。随机真实红果下载、1080与720实际解码、故障注入后的自动换档、暂停/位置保留、有界耗尽与原生重试均通过。

以上为发行前独立测试包证据，详见 [自动清晰度验收](auto-1080-preview.md)。最终4.8三端构建、Mac签名公证、Windows CI及远端发行核验待完成后补记。

## 边界

画质档位取决于上游；请求某一档也可能返回更高实际尺寸，判断依据为解码后的真实分辨率。Mac最终包需完成Developer ID签名、Apple公证Accepted及装订。Windows EXE未配置代码签名。未覆盖实体Windows/Intel、干净Gatekeeper、长期弱网和完整跨版本应用内自动更新；本轮不替换正式安装。
