# 7.6 四平台正式发行

状态：已于 2026-11-18 18:17:30（Asia/Shanghai）正式公开并设 Latest。公开版本 `7.6`，内部版本 `7.6.0`，桌面构建 `7.6.1`，冻结源码 `6a3df3b0b03e8a63589a73e375e9058f181930e8`，标签 `v7.6`，Release ID `449788313`。

发行范围：macOS Apple Silicon arm64、macOS Intel x64、Windows x64、Linux x64 AppImage。Docker、TV APK与手机APK不在本轮附件或验收范围。

> **Android手机APK／Android TV版：** 请前往 [N3urda/hongguoTV](https://github.com/N3urda/hongguoTV) 下载。该项目独立维护；版本、兼容性与测试状态以该项目发布页为准，不计入本项目的四平台附件或验收。

## 本轮修复

- 下载删除改为先隔离、再复验文件身份，关闭“身份检查后替换文件”被误删的窗口。
- 旧下载记录只有在文件时间落在本次下载窗口内时才可认领；同毫秒开始与结束的合法记录仍可恢复。
- 合并成功发布后再次校验输出时长、画面和必要音轨；校验失败保留全部分集。
- 文件发布后发生迟到取消，不再把已经完成且身份有效的下载覆盖成“已停止”。
- 播放进度改为串行基于最新记录更新，避免观看记录后台检查与播放器保存互相覆盖。
- 双击未下载分集只加入下载，不再先触发表演播放；延迟单击会由双击取消。
- 合并提交期间禁止用遮罩或取消键假取消；合并删源后立即重新验盘，不保留空剧选项。
- 损坏或可替换的本地媒体 token、代理 query 凭据、账号网页会话代理和 DNS 缓存边界已收紧。

## 验证门槛

- 最终冻结源码必须通过仓库全量 `npm test`。
- 双Mac必须从同一冻结源码重新构建，App与DMG重新Developer ID签名、Apple公证Accepted并装订；更新ZIP必须从最终签名App重新生成。
- Windows必须由冻结源码工作流生成安装版、便携EXE、便携ZIP、更新清单和对应媒体源码；EXE保持未签名。
- Linux必须由原生Ubuntu x64工作流生成AppImage、对应媒体源码和摘要，并完成启动与可用媒体资源验收。
- Draft必须汇总四平台应用包、必要更新清单、精确源码、对应媒体源码和SHA256；远端状态、大小和摘要全部回读后才公开并设Latest。

- 双 Mac、Windows x64、Linux x64 AppImage 共 23 份正式附件，总大小 1,560,413,823 字节；22 份文件逐项核对本地与 GitHub SHA256、远端大小及 `v7.6` 下载地址，全部 23 个匿名入口返回可下载内容。
