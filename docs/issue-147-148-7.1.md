# #147／#148：7.1 下载修复候选

> 以下为开发／审查阶段快照；7.1已正式发布，最终范围、包身份与验收见[正式回执](release-7.1.md)。

基于正式标签 `v7.0`（`3f5927d`）。本轮仅本地代码修复，未修改版本号、构建发行包、发布或替换正式应用。

## 修复范围

- #148：首次提交按目录顺序入队，但任务记录倒序保存；暂停后继续和批量重试会按记录顺序重新入队。共用调度器现在只在同一部剧占用的队列位置内按集号升序整理，保留不同剧的既有位置、并发数、路径占用保护和请求冷却。单项／自动重试也使用同一规则；已运行任务不抢占，尚未到期的重试仍等待。
- #147：文件编号超出 JavaScript 安全整数范围时，旧归属检查会拒绝自己刚创建的临时文件，随后下载落盘、临时文件清理和记录删除一并失败。新文件身份用 BigInt 读取，将设备号、文件号及纳秒创建时间保存为十进制字符串，避免 JSON 持久化损失精度。普通下载、CENC 解密与 ByteVC2 输出使用相同校验；空间统计仍使用普通数字。
- 旧版安全数值收据继续按旧规则校验。已经丢失编号精度的旧收据、被替换的文件和无法确认归属的目录继续保留，不自动认领或强制删除。
