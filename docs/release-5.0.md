# 红果短剧 5.0

**状态：已正式发布。** 5.0（内部 `5.0.0`）已于 2026-10-30 15:21（Asia/Shanghai）正式发布，标签 `v5.0`，冻结源码 `1fa218a196478c9bd3908bea9666bc23f23b921f`。三端 16 项附件及其远端 SHA256、大小匹配；双 Mac App 与 DMG 的 Developer ID 签名、Apple 公证 Accepted、票据装订、最终 DMG 只读挂载及包内文件匹配通过；源码 CI 41016309687 与 Windows CI 41016337531 均通过；10 个匿名下载入口、Mac x64 Rosetta 启动、真实素材播放和观看记录界面验收通过。Windows EXE 未签名。

## 观看记录

- 检测范围和“隐藏同剧低季”保存到本机，重启后恢复；损坏的保存值回退默认，保存失败会提示。
- 支持明确的中文/数字季号、没有“第”的季号、括号内季号及season写法。年份与无效季号保持防误匹配。
- 标题末尾裸数字、标题中间数字变化、中英文数字写法及轻微改名，仅显示“疑似同剧（仅提示）”。
- 疑似关系不用于低季隐藏、批量归组、更新红点或系统通知；点击核对也不清除原剧更新标记。不同来源继续隔离，不删除观看记录或视频。
- 同一剧号后续改为明确季名时，新标题覆盖旧疑似缓存，转入明确续作后可正常确认更新标记。

## 识别边界

疑似匹配限制标题长度和差异数量，只提示已有本机记录或来源返回的候选；每条最多五项。大幅改名仍可能漏提示，标题相近不能证明作品关系。
