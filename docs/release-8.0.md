# 8.0 四平台发行目标

状态：源码／发行目标，尚未公开。公开版本 `8.0`，内部版本 `8.0.0`，桌面构建 `8.0.1`。

发行范围：macOS Apple Silicon arm64、macOS Intel x64、Windows x64、Linux x64 AppImage。Docker、TV APK与手机APK不在本轮附件或验收范围。

> **Android手机APK／Android TV版：** 请前往 [N3urda/hongguoTV](https://github.com/N3urda/hongguoTV) 下载。该项目独立维护；版本、兼容性与测试状态以该项目发布页为准，不计入本项目的四平台附件或验收。

## 本轮修复

- 对应 GitHub Issue #179：App 播放主接口、备用主机、单集模型、`video_tab` 和旧接口都返回空响应时，复用同一匿名身份完成有界探测，并新增两个官方单集 `video_model` 主机入口。
- 全部 App 入口仍为空时，改用官网网页播放器使用的完整公开兜底片源。实测为 H.264/AAC、360 × 640 的完整分集，不是 SEO 页面的 10 秒预览。
- 自动在线播放可接受完整低画质兜底，减少先等待两轮高画质失败；手动固定在线画质仍不静默降级。固定 1080P 下载允许降级时，下载管理会明确显示实际 360P。
- 匿名身份复用保留取消语义；设备注册 socket 由共享请求持有，最后一组消费者取消时才关闭。
- 对应 GitHub Issue #178：官方弹幕里的 `[笑哭]`、`[捂脸]`、`[爱慕]`、`[没看够]`、`[饱了]` 等代码显示为系统彩色表情图片；未知代码保留原文。
- 弹幕屏蔽、去重、聚合、宽度估算和长文本截断继续基于原正文，替换只发生在显示阶段。

## 定向验证

- 取源、恢复、身份和公开兜底共 40 项定向测试通过。
- 真实 axios 注册 socket 的最终消费者取消测试通过；此前同一用例曾超时。
- 弹幕、评论与官方弹幕共 80 项测试通过。
- UI 状态回归通过，覆盖自动在线画质允许完整低画质兜底。
- `npm run build:react` 通过。
- 开发窗口冷启动《嫌疑人的秘密2藏金生死线》第 1、2 集，完整 360P 兜底分别静音连续播放超过 19 秒和 13 秒；进度跳转、全屏和切集通过。
- 固定 1080P 下载第 2 集完成并提示实际 360P；文件实测 8,260,013 字节、H.264 360 × 640、97.38 秒，本地静音播放超过 10 秒。
