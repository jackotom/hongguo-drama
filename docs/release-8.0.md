## 本轮修复

- 对应 GitHub Issue #179：App 播放主接口、备用主机、单集模型、`video_tab` 和旧接口都返回空响应时，复用同一匿名身份完成有界探测，并新增两个官方单集 `video_model` 主机入口。
- 全部 App 入口仍为空时，改用官网网页播放器使用的完整公开兜底片源。实测为 H.264/AAC、360 × 640 的完整分集，不是 SEO 页面的 10 秒预览。
- 自动在线播放可接受完整低画质兜底，减少先等待两轮高画质失败；手动固定在线画质仍不静默降级。固定 1080P 下载允许降级时，下载管理会明确显示实际 360P。
- 匿名身份复用保留取消语义；设备注册 socket 由共享请求持有，最后一组消费者取消时才关闭。
- 对应 GitHub Issue #178：官方弹幕里的 `[笑哭]`、`[捂脸]`、`[爱慕]`、`[没看够]`、`[饱了]` 等代码显示为系统彩色表情图片；未知代码保留原文。
- 弹幕屏蔽、去重、聚合、宽度估算和长文本截断继续基于原正文，替换只发生在显示阶段。
