# 红果短剧 5.6

状态：源码／发行目标，内部版本 `5.6.0`，拟发布标签 `v5.6`。当前正式版仍为 5.5。

## 本轮修复与交互

- #96：官网与扫码登录确认只验证真实账号，不再同时等待匿名 App 设备注册；观看记录按需获取匿名设备。注册或记录加载失败不撤销已确认登录。官网登录验证失败会回显错误。
- 匿名设备注册失败后遵守10秒冷却，期间不重复向上游注册；成功后每次播放仍使用独立身份。该改动不能保证上游解除网络限制或限流。
- #93：双击视频画面进入／退出全屏，保留播放或暂停状态；播放控制条新增下一集按钮，末集或后续未开放时禁用。竖屏沿用现有填满窗口逻辑。原有切集交接保留，不承诺消除网络缓冲。
- #94：长按快进键（默认右箭头）300毫秒后临时2倍速，松手或失焦恢复原速度；短按仍跳5秒。输入框、菜单和快捷键自定义沿用原边界。
- #95：真实复现《我都元婴期了，你跟我说开学第四季》首集，内联与备用接口均只提供ByteVC2。明确提示当前不支持该编码；没有将ByteVC2误认为HEVC或绕过身份、时长、画质和地址校验。此播放问题未解决，需在官方App观看。

## 验证与限制

定向离线回归覆盖账号确认与取消、注册冷却、原有备用源安全校验、双击、长按／释放／失焦、短按跳转及控制条下一集。已真实读取#95分集与两种接口的编码元数据；单次匿名注册成功，不代表百集下载后的限流已复现或消除。
