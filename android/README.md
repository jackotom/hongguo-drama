## 安装

将 `build/hongguo-personal-1.1.apk` 传到手机，用文件管理器打开；按系统提示允许该文件管理器安装应用。安装名称为“红果·自用”，包名 `io.github.hongguo.personal`。

这是独立包，不覆盖官方红果或桌面版。首次进入发现页会联网。可在应用“说明”中查看流量、缓存与来源限制。

## 明确限制

- 当前1.1已在连接手机（Android16）覆盖安装，目录与海报实测恢复；完整播放仍待验收，不能当作实播通过。
- 整集准备完成后播放；首播等待取决于网络、单集大小和处理速度。一次仅准备当前集，不做后台预下载。
- 单集上限64MB，临时文件在私有缓存。离开播放页清理缓存，启动时清理上次遗留。不是离线下载库。
- ByteVC2没有移植桌面FFmpeg转换，不支持；HEVC仍依赖手机WebView与系统解码器。
- 上游接口未公开，可能失效或拒绝。明确拒绝立即停止；官网预览不会冒充完整视频。
- 未做账号登录、云同步、NAS、弹幕、画中画与通知。

## 本地构建

根项目先安装锁定的npm依赖。再执行：

```sh
npm --prefix android ci --ignore-scripts
npm --prefix android test
python3 android/build.py
```

复用根项目esbuild；安卓新增运行依赖仅 `buffer` 及其两项小型依赖。构建使用已安装的JDK21、Android SDK36、build-tools36.0.0，不下载Gradle。

可用 `JAVA_HOME`、`ANDROID_HOME` 指向其他机器上的同等工具。`build.py` 执行资源编译、Java编译、DEX、对齐、个人签名、签名与包信息校验；回执在 `build/verification.json`。安卓个人版版本独立于桌面版6.0。

签名材料保存在 `android/.private/`，已忽略；仅用于后续同包升级，应私下保留。不要上传密钥或密码文件。构建产物、生成的JS与复制的授权文本也已忽略。

根项目GPL许可与第三方声明随APK打包；安卓Buffer等依赖的完整MIT许可汇总到APK的 `assets/ANDROID-DEPENDENCIES.txt`。桌面算法原作者标注保留在对应源码中。
