# Mac 版安卓移植

目标：直接打包共享 React App 和现有播放器、业务页面，安卓仅负责平台桥和手机触控。保留旧 `web/app.js` 给 iOS；不改桌面发行和 iOS。

1. 独立打包入口：共享 `src/App.jsx`、业务组件和样式，安卓桥先初始化；底栏、更多菜单、触控选集、系统返回与后台暂停。
2. 平台桥：复用签名、目录、搜索、详情、历史分组与解密模块；本机档案、断点、下载队列、文件令牌、取消和原子持久化。没有实现的平台能力明确报错，禁止空成功。
3. 媒体：对齐桌面 App 片源 Referer 与403一次重试；保留拒绝、质量回退、身份校验。安卓硬件解码与兼容转换分别记录状态，不继承桌面验证。
4. 验证：首轮限桥接回归及手机核心流程两项；APK构建和签名随安装准备。真实随机红果素材，播放前音量为0；独立数据，不触碰桌面视频。记录发现、搜索、详情、播放、切集、下载、记录、收藏、后台、横屏的实际结果。

完成标准：安装包实际使用共享界面，核心流程有真实结果；无法完成的能力及验收不冒充成功。只本地构建、签名和已连接手机安装，无外部发布或付费授权。
