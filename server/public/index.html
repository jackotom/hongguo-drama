API 使用

让脚本与 NAS 自动化调用相同功能。所有请求都需要访问令牌。

连接与鉴权

服务地址：。在请求头添加 Authorization: Bearer <访问令牌>，JSON 请求添加 Content-Type: application/json。

令牌等同管理权限，请通过可信局域网或 HTTPS 访问；不要把令牌放进链接。

接口速查

方法与路径用途 / 请求正文
GET /api/status验证令牌、查看下载目录与版本
GET /api/search?q=剧名&page=1搜索，结果位于 results
GET /api/series/:seriesId剧集详情，series.episodes 提供分集 vid
POST /api/downloads{"seriesId":"剧集ID","episodeIds":["分集vid"],"quality":"auto"}
GET /api/tasks下载与合并状态，结果位于 tasks
POST /api/tasks/:id/retry重试失败、取消或中断的任务，正文 {}
POST /api/tasks/:id/cancel取消等待或运行中的任务，正文 {}
POST /api/merge{"taskIds":["下载任务ID1","下载任务ID2"]}，至少两个同剧已完成分集
GET /api/files/:taskId获取已登记的完成文件，仍需鉴权；也可直接从 NAS 挂载目录读取

画质支持 auto、720p、1080p。接口返回 success；失败原因位于 error。本服务仅提供红果来源，不提供账号登录与在线播放。
